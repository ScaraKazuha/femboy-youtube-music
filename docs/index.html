Femboy YouTube Music

YouTube Music as a small, cute Windows app.

Install for Windows

Free · about 3 MB · Windows 10/11 (64-bit) · no admin rights needed

Keeps playing

Close the window and music continues from the tray. Click the tray icon to bring it back.

Updates itself

New versions are offered at startup and installed with one click.

Tiny and clean

Written in Rust. Uses the browser engine already built into Windows, so there is nothing heavy to download.

How to install

  1. Click Install for Windows and open the downloaded file.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. The installer is not code-signed, so Windows does not know the publisher yet.
  3. Click Next and Install. The app opens and a shortcut appears on your desktop.
